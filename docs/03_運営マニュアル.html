4. 店舗の追加・編集・削除

4-1. 新規店舗を追加する

1
店舗管理ページ
左メニュー「店舗管理」
2
「新規追加」ボタン
右上のオレンジボタン
3
情報入力
必須項目を全て埋める
4
登録ボタン
即座に公開サイトに反映

入力項目チェックリスト

必須:

  • ☐ 店舗名
  • ☐ 短い紹介（50字、カード表示用）
  • ☐ 詳しい紹介（400字、店舗詳細ページ用）
  • ☐ 都道府県・住所
  • ☐ 大カテゴリ・中カテゴリ

任意（あるとSEOに有利）:

  • ☐ メイン画像URL（無いと自動でランダム画像）
  • ☐ 電話番号・営業時間・定休日・料金目安
  • ☐ 公式サイト / Instagram / Googleマップ URL
  • ☐ 特徴タグ（駅近・個室・キッズOK等、カンマ区切り）
  • ☐ おすすめポイント・提供サービス

表示設定のフラグの意味

フラグ 効果 推奨
おすすめに表示 検索結果で上位表示 質の高い店舗にON
有料プラン店舗 内部管理用ラベル 有料契約があればON
プレミアム掲載（PR表示） 検索結果の最上位＋PRバッジ 課金店舗のみON
認証済み店舗 店舗オーナーが認証済み 申請時に切替

4-2. 店舗を編集する

  1. 店舗管理ページの一覧で対象店舗の「編集」リンク
  2. フォームを修正
  3. 「保存する」ボタン

⚠️ 「サンプル」と書かれた行は編集できません（システム同梱のデモデータ）

4-3. 店舗を削除する

  1. 編集ページを開く
  2. ページ上部の「この店舗を削除」赤いボタン
  3. 押すと即座に削除（取り消し不可・注意）

5. 広告の管理

5-1. 広告を追加する

  1. 左メニュー「広告管理」

  2. 上部の「新しい広告を追加」フォームに入力:

    • タイトル: 「【公式】HP制作 30万円〜」のような訴求コピー
    • 広告主名: 「WEB制作.JP」など
    • 画像URL: 正方形バナー画像（推奨600x600px）
    • クリック先URL: ランディングページ
    • 表示場所: 左サイド / 右サイド
    • 広告タイプ: バナー広告 / プレミアム掲載
    • 優先度: 数字が大きいほど優先表示（0-1000）
    • 表示開始/終了日時: 空欄なら常時表示
    • すぐに表示する: チェックON で公開

  3. 「広告を追加」ボタン

5-2. 広告の停止・再開・削除

下部の登録済み広告テーブルから:

  • 停止: 一時的に非表示（後で再開可能）
  • 再開: 停止した広告を再表示
  • 削除: 完全削除（取り消し不可）

5-3. 広告掲載のセキュリティルール（覚える鉄則）

  • ⚠️ 画像URL・リンク先URLは必ず https:// で始まるものを使う
  • ⚠️ 公序良俗に反する広告は掲載しない
  • ⚠️ 広告主名は省略しない（ステマ規制対応）

6. 写真ファイルの管理

6-1. 写真のアップロード制限

項目 上限
1リード（申込み）あたり 1枚（店舗ページのメイン画像）
ファイルサイズ 最大 5MB
ファイル形式 JPG / PNG / WebP
推奨アスペクト比 16:10（横長）
Storage全体（無料プラン） 1GB

6-2. アップロードされた写真の保存場所

すべての写真は Supabase Storage の business-images バケット に保存されます。

business-images/
  └ lead-uploads/
      └ 2026-05/   ← 月別フォルダ（自動生成）
          ├ 0c689d1c-...png
          ├ 137e0ae3-...png
          └ ...

→ ファイル名は UUID（ランダム英数字）。セキュリティ目的で意図的に分かりにくくしてます。

6-3. ⚠️ なぜStorageを直接見ても「どの店の写真か」分からないのか

これは仕様で、以下の理由があります:

理由 説明
推測対策 「cafe-aoba.png」のような名前だと、他店のURLも当てやすい
個人情報保護 店名・電話番号がファイル名に混入するのを防ぐ
衝突防止 同名店舗でも絶対に重複しない
URL安全 日本語・絵文字でURLエラーにならない

6-4. 「どの店の写真か」を探す正しい方法

A. 管理画面のリード一覧から探す（推奨）

管理画面 → リード管理
   ↓
左端のサムネ画像 + 隣の店舗名で判別

B. Supabase Studio SQL Editor から検索

SELECT company_name, image_url, created_at
FROM leads
WHERE image_url IS NOT NULL
ORDER BY created_at DESC;

これで「店舗名 + 画像URL」のペアが一覧で見えます。

6-5. 写真の削除

店舗情報を削除する場合（管理画面から）: 店舗を削除しても Storage の画像ファイルは残る ことに注意。
本格運用時は「店舗削除時に Storage の画像も自動削除」する仕組みを後で追加可能です。

Storage UIから手動削除する場合:

  1. https://supabase.com/dashboard/project/uzlpnczydfuejjdyqmju/storage/buckets/business-images
  2. 削除したい画像を右クリック → Delete
  3. ※ 該当リード（leads.image_url）も併せて更新するのを忘れずに

8. メール通知の設定

リードが届いた時、運営者に自動でメール送信されます。

必要な設定（一度だけ）

  1. Resend.com にアカウント登録（無料・カード不要）
    👉 https://resend.com/signup
  2. ダッシュボードで API Key を発行（re_ で始まる文字列）
  3. Renderのダッシュボードで以下の環境変数を追加:
変数名 値の例
RESEND_API_KEY re_xxxxxxxxxxxx
NOTIFY_EMAIL_TO info@yourdomain.com（あなたの受信メール）
NOTIFY_EMAIL_FROM onboarding@resend.dev（最初はこれでOK・後でドメイン認証して変更）
  1. Render が自動再デプロイ → 次のリードから自動メール送信

メール送信のテスト方法

トップページの「無料掲載」フォームから自分宛にテスト送信。10秒以内にメールが届けばOK。

9. トラブル対応

よくある症状と原因

症状 原因 対処
サイトが「Loading」のまま Render が15分スリープ中 30〜60秒待つ
ログインできない パスワード違い or ロック中 15分待つ or .envで再設定
新しいリードが来ない フォームエラー or レート制限 ブラウザのコンソール確認
管理画面で店舗追加できない Supabase未接続 Renderの環境変数を確認
メール通知が来ない RESEND_API_KEY 未設定 第8章を再確認
画像が表示されない 画像URL間違い or ドメイン未許可 next.config.tsのremotePatterns追加

Render の状態確認

https://dashboard.render.com/web/srv-d83ct8u7r5hc73blkn7g
  • Live = 正常稼働中
  • Deploying = 更新中（2-5分待つ）
  • Failed = エラー（Logsタブで詳細確認）

Supabase の状態確認

https://supabase.com/dashboard/project/uzlpnczydfuejjdyqmju
  • ACTIVE_HEALTHY = 正常稼働中
  • INACTIVE = pause中（誰かが画面開けば自動復帰）
  • PAUSED_BY_USER = 手動停止中（手動で再開必要）
