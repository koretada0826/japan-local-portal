## 1. こんなお悩み、ありませんか？

- ☐ ホームページを作ったが、Googleで検索しても出てこない

**多くの地域事業者様が「やりたいけど、わからない・高い」で止まっています。**

## 4. 掲載できる情報

- 店舗名・住所・電話番号
- 営業時間・定休日・料金目安
- 写真（メイン画像）
- 紹介文・おすすめポイント
- 業種・特徴タグ（駅近・個室・キッズOK 等）
- 公式サイト・SNS・Googleマップへのリンク

→ **Googleビジネスプロフィールよりも詳しく書ける**のが強みです。
